# Image candidates: sf-east group

Research only. Nothing was downloaded into the repo and no one was contacted. Checked 2026-10-06.

Projects: candlestick-point, hunters-point-shipyard, potrero-power-station, pier-70, mission-rock,
mission-bay, india-basin, potrero-hope-sf, sunnydale-hope-sf, schlage-lock.

How licenses were checked: for each Wikimedia Commons file I read the license template, author,
date and source on the file's own page (through the Commons API: wikitext and extmetadata).
I opened a small preview of the key images to confirm what they show. NC, ND and "all rights
reserved" images were left out. For example, Flickr `scottrklinephotog/32122160778` ("Dogpatch Power
Station Unit 3", 2018) is all rights reserved.

How credit lines work: they follow the TASL pattern (title, author, source, license). For CC BY and
CC BY-SA, the credit must name the author, link the license and say whether the image was changed.
CC BY-SA also requires that any edited version, such as a crop, be shared under the same license. CC0,
public-domain and PD-USGov images need no credit, but giving one is good practice.

"Current" means the photo matches conditions on the ground today as far as we can tell. "Old" means
the site has changed since it was taken. Direct original URLs are listed for reference only. Don't
hotlink them: copy the file into the build if it's used.

Coverage gaps:
- Flickr: I searched with the license filter set to CC BY, CC BY-SA, CC0 and PDM. The search page
  returned only partial results to automated requests, so Flickr coverage is incomplete. The
  matches I did find (Pier 70 in 2017, Potrero interiors in 2008, Hunters Point in 2018) were older
  than or weaker than the Commons images below, so none are listed.
- Openverse: its API needs a token from this environment, so it wasn't searched.
